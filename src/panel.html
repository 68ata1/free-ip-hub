只有指定国家模式需要设置目标国家（ANY = 全球），按 VPNGate 评分选择；延迟优先（实测延迟最低）和速度优先（VPNGate 测速最高）在全球范围内挑选，不限国家。选择顺序：先看「优先国家 / 地区」（有勾选时，这些国家的 IP 永远排在前面；它们都连不上才会换别的国家），再按延迟 / 速度，并优先已确认的住宅 IP；三种模式都会跳过「不连接的国家」。定时择优：agent 每 16 分钟重新抓取并测速 VPNGate 节点，若发现比当前线路更优的 IP 就自动切换（会短暂中断 15–60 秒，手动固定的 IP 不会被换掉）。修改后点「保存策略」生效。停用代理服务后不再接受新连接，已建立的连接会自然结束。
